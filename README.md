# لينكدإن على طريقتك

عرض ورشة عن لينكدإن من 31 شريحة، يفتح من المتصفح مباشرة:

**https://evani624.github.io/linkedin-workshop/**

## التنقل

- على الكمبيوتر: السهم أو المسافة للخطوة الجاية، السهم المعاكس للرجوع، `Esc` لكل الشرائح، `F` لملء الشاشة، `T` لإيقاف المؤقت.
- على الجوال: ضغطة على الشريحة للخطوة الجاية، والأزرار اللي بجانب الشريحة للرجوع ولقائمة الشرائح. لف الجوال بالعرض عشان الشريحة تملأ الشاشة.

## التشغيل والبناء

```
npm ci
npm run build
```

الناتج في `dist/`: أربعة ملفات ثابتة، والخطوط مضمّنة فيها، فالعرض يشتغل بدون إنترنت.

## النشر

كل `push` على `main` يبني العرض وينشره على GitHub Pages تلقائيًا (`.github/workflows/pages.yml`).

## الفحص

سكربتات الفحص في `qa/` (Python و Playwright، على Chromium و WebKit وبمقاسات الجوال). التفاصيل في `qa/README.md`.

## المكونات

React و React Bits و GSAP. الخطوط: Readex Pro و IBM Plex Sans Arabic و IBM Plex Mono.
